# Tobe-Writer — คลังต้นฉบับหนังสือและเว็บไซต์ประวัติศาสตร์

คลังนี้ออกแบบด้วยหลัก **Single Source of Truth** — ต้นฉบับ Markdown และภาพประกอบใน `books/<book_id>/` ชุดเดียวกัน สามารถนำไปใช้ได้ทั้ง:
1. **ส่งออกหนังสือ PDF มาตรฐานโรงพิมพ์** (ผ่าน `tools/build_book_pdf.py`)
2. **นำเข้าเป็นข้อมูลเว็บไซต์** (อ่าน `book.json`, `episodes/*.md`, และ `images/` เพื่อสร้างหน้าเว็บอ่านออนไลน์ตาม `slug`, `category`, และ `theme` ของแต่ละเรื่อง)

> แต่ละเล่มไม่จำเป็นต้องใช้แนวการเล่าเรื่องแบบ "กระดานกลศึก" เหมือนกัน สามารถกำหนด `category`, `eyebrow`, `theme`, และโครงสร้างเนื้อหาเฉพาะตัวของบุคคล/เรื่องนั้นๆ ใน `book.json` ได้อย่างอิสระ

## โครงสร้างโฟลเดอร์

```text
Tobe-Writer/
├── README.md                          # คู่มือโครงสร้างโปรเจกต์
├── tools/
│   └── build_book_pdf.py              # สคริปต์กลางสร้าง PDF มาตรฐานโรงพิมพ์
├── web/                               # (อนาคต) ซอร์สโค้ดเว็บไซต์หรือตัวส่งออกข้อมูลเว็บ
└── books/
    ├── 01_กระดานศึกพระเจ้าตาก/       # เล่มที่ ๑: สมเด็จพระเจ้าตากสินมหาราช (๔ ภาค ๒๐ ตอน)
    │   ├── book.json                  # เมตาเดตา (slug, category, theme, parts)
    │   ├── episodes/                  # ต้นฉบับ Markdown รายตอน (ใช้ร่วมกันทั้ง PDF และเว็บ)
    │   ├── images/                    # ภาพฉาก 16:9 และแผนที่/ภาพประกอบ
    │   └── output/                    # ไฟล์ PDF ที่ส่งออก
    └── 02_พระนเรศวร/                 # เล่มที่ ๒: สมเด็จพระนเรศวรมหาราช (เตรียมพร้อม)
        ├── book.json
        ├── episodes/
        ├── images/
        └── output/
```

## วิธีสร้างไฟล์ PDF มาตรฐานโรงพิมพ์

```powershell
# สร้างเฉพาะภาคที่ 1 ของเล่มพระเจ้าตาก
python tools/build_book_pdf.py --book 01_กระดานศึกพระเจ้าตาก --part 1

# สร้างฉบับรวมเล่มสมบูรณ์ (ทุกภาค)
python tools/build_book_pdf.py --book 01_กระดานศึกพระเจ้าตาก --all
```
