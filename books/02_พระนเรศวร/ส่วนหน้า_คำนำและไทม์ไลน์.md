# ส่วนหน้า: คำนำและไทม์ไลน์ ๔ ทศวรรษ
**ชื่อหนังสือ:** ๔ ทศวรรษ สมเด็จพระนเรศวรมหาราช  
**ชื่อรอง:** จากองค์ประกันหงสาวดี สู่กษัตริย์นักรบผู้พลิกดุลอำนาจอุษาคเนย์ (พ.ศ. ๒๐๙๘–๒๑๔๘)

---

## คำนำ: นักสืบประวัติศาสตร์ในท้องพระโรงและสมรภูมิ

เรื่องราวของ **สมเด็จพระนเรศวรมหาราช** เป็นหนึ่งในหน้าประวัติศาสตร์ที่คนไทยคุ้นเคยมากที่สุด ตั้งแต่ภาพจำของการชนไก่ในกรุงหงสาวดี การหลั่งทักษิโณทกประกาศอิสรภาพที่เมืองแครง พระแสงปืนข้ามแม่น้ำสะโตง ไปจนถึงมหายุทธหัตถีที่หนองสาหร่าย ทว่ายิ่งเรื่องเล่าถูกถ่ายทอดซ้ำผ่านมุขปาฐะ วรรณคดี และพงศาวดารฉบับชำระชั้นหลังมากเท่าใด เส้นแบ่งระหว่าง **"ข้อเท็จจริงร่วมสมัย"** กับ **"ตำนานที่ถูกแต่งเติมในยุคหลัง"** ก็ยิ่งเลือนรางลงเท่านั้น

หนังสือ **"๔ ทศวรรษ สมเด็จพระนเรศวรมหาราช"** เล่มนี้ จึงชวนผู้อ่านถอยออกมามองประวัติศาสตร์ด้วยสายตาของ **"นักสืบประวัติศาสตร์"** ที่ยืนอยู่ทั้งในท้องพระโรงและสมรภูมิ เราจะกางหลักฐานจากหลายแผ่นดินวางเทียบกันบนโต๊ะ—ตั้งแต่ *พระราชพงศาวดารกรุงศรีอยุธยา ฉบับหลวงประเสริฐอักษรนิติ์* ที่บันทึกศักราชอย่างแม่นยำ, *ฉบับพันจันทนุมาศ (เจิม)*, *ฉบับพระราชหัตถเลขา*, *คำให้การชาวกรุงเก่า*, ไปจนถึง *มหาราชวงษ์ พงษาวดารพม่า* (แปลจาก *Hmannan Yazawin* หรือพงศาวดารฉบับหอแก้ว), เอกสารราชวงศ์หมิง (*Ming Shilu*), และบันทึกพ่อค้า-บาทหลวงชาวยุโรป

ตลอดทั้ง ๔ ภาค ๑๖ ตอน ผู้อ่านจะได้เห็นว่าเบื้องหลังพระอัจฉริยภาพทางการทหาร คือเกมการเมืองอันซับซ้อนระหว่างราชวงศ์สุโขทัยในพิษณุโลก ราชสำนักกรุงศรีอยุธยา และจักรวรรดิตองอูแห่งกรุงหงสาวดี และทุกครั้งที่เรื่องราวแตะถึงเกร็ดตำนานหรือพงศาวดารชั้นหลัง หนังสือเล่มนี้จะบอกผู้อ่านอย่างซื่อตรงเสมอว่าข้อความนั้นมาจากหลักฐานใด—เพื่อให้เราเข้าใจทั้งความจริงทางประวัติศาสตร์และความทรงจำร่วมของแผ่นดินไปพร้อมกัน

## เส้นเวลา ๔ ทศวรรษแห่งแผ่นดินพระนเรศวร (พ.ศ. ๒๐๙๘ – ๒๑๔๘)

| พ.ศ. | ภาค / ตอน | เหตุการณ์สำคัญบนกระดานศึก |
| :--- | :--- | :--- |
| **๒๐๙๘ – ๒๑๐๖** | ภาค ๑ / ตอนที่ ๑ | ประสูติกาล ณ พระราชวังจันทน์ เมืองพิษณุโลก ท่ามกลางดุลอำนาจสุโขทัย–อยุธยา จนถึงศึกช้างเผือก |
| **๒๑๐๖ – ๒๑๑๔** | ภาค ๑ / ตอนที่ ๒ | เสด็จเป็นองค์ประกัน ณ กรุงหงสาวดี เทียบปมปี ๒๑๐๖ กับ ๒๑๑๒ และแยกตำนานชนไก่–พระสุพรรณกัลยา |
| **๒๑๑๔ – ๒๑๑๗** | ภาค ๑ / ตอนที่ ๓ | นิวัตพิษณุโลกในฐานะพระมหาอุปราช และเสด็จร่วมทัพตีเวียงจันทน์จนทรงประชวรพระโรคทรพิษ |
| **๒๑๒๑ – ๒๑๒๔** | ภาค ๑ / ตอนที่ ๔ | ขับไล่ทัพกัมพูชาของนักพระสัตถาที่ชัยบาดาล–เพชรบุรี และทรงนำเรือไล่ล่าพระยาจีนจันตุกลางเจ้าพระยา |
| **๒๑๒๔ – ๒๑๒๗** | ภาค ๒ / ตอนที่ ๕ | สิ้นพระเจ้าบุเรงนอง ศึกเมืองคัง และกบฏพระเจ้าอังวะ (Thado Minsaw) จุดร้าวฉานในจักรวรรดิหงสา |
| **๒๑๒๗** | ภาค ๒ / ตอนที่ ๖ | ประกาศอิสรภาพ ณ เมืองแครง และยุทธการตีฝ่าข้ามแม่น้ำสะโตงที่สุรกรรมาสิ้นชีพ |
| **๒๑๒๗ – ๒๑๒๘** | ภาค ๒ / ตอนที่ ๗ | เทครัวหัวเมืองเหนือลงอยุธยา ปราบกบฏสวรรคโลก–พิชัย และตีทัพพระยาพะสิม–พระเจ้าเชียงใหม่แตกพ่าย |
| **๒๑๒๙ – ๒๑๓๓** | ภาค ๒ / ตอนที่ ๘ | พระเจ้านันทบุเรงปิดล้อมพระนคร ๕ เดือน (ธ.ค. ๒๑๒๙ – พ.ค. ๒๑๓๐) และเสด็จขึ้นครองราชย์ พ.ศ. ๒๑๓๓ |
| **๒๑๓๓ – ๒๑๓๔** | ภาค ๓ / ตอนที่ ๙ | ปราบทัพพระมหาอุปราชาครั้งที่ ๑ จับพระยาพะสิมที่ตำบลตะเข้สามพัน และจัดทัพวังหลวง |
| **๒๑๓๕ – ๒๑๓๖** | ภาค ๓ / ตอนที่ ๑๐–๑๑ | ทัพหลวงหงสาตั้งที่ตระพังกรุ นำสู่มหายุทธหัตถีที่หนองสาหร่าย (ม.ค. ๒๑๓๖ ตามปฏิทินสากล) เทียบหลักฐาน ๓ ฝ่าย |
| **๒๑๓๕ – ๒๑๓๗** | ภาค ๓ / ตอนที่ ๑๒ | พระราชสาส์นเสนอช่วยราชวงศ์หมิงรบญี่ปุ่น และกรีฑาทัพตีกรุงละแวกปิดแนวรบตะวันออก |
| **๒๑๓๘ – ๒๑๔๓** | ภาค ๔ / ตอนที่ ๑๓–๑๔ | ข้ามเทือกเขาตะนาวศรีล้อมกรุงหงสาวดี ๒ ครั้ง จนหงสาวดีล่มสลายและตามล้อมพระเจ้าตองอู |
| **๒๑๔๓ – ๒๑๔๗** | ภาค ๔ / ตอนที่ ๑๕ | พันธมิตรการค้าทางทะเลกับสเปน–โปรตุเกส–ชาวญี่ปุ่น และจัดระเบียบล้านนา–รัฐฉานต้านอังวะ |
| **๒๑๔๗ – ๒๑๔๘** | ภาค ๔ / ตอนที่ ๑๖ | กรีฑาทัพปราบพระเจ้าญองยันแห่งอังวะ ทรงพระประชวรและเสด็จสวรรคต ณ ทุ่งแก้ว เมืองหาง (๒๕ เม.ย. ๒๑๔๘) |
