# ไอเดียเล่ม ๔ — ข้อมูลดิบ (ยังไม่ตัดสินใจ)

บันทึกจากการคุยหลังปิดเล่ม ๓ ใช้เป็นวัตถุดิบ ไม่ใช่แผนงาน ยังไม่ได้เลือกเรื่องหรือเครื่องยนต์

## ลายเซ็นของชุด (คงไว้ทุกเล่ม — ตามที่ผู้เขียนกำหนด)
1. ฉากเปิดที่จับต้องได้
2. แผนที่ที่ช่วยให้เข้าใจเรื่อง
3. การเทียบหลักฐานหลายฝ่าย
(ภาพหมึกน้ำ ๑ ฉากต่อตอน, แผนที่ celadon + ป้ายภาษาไทย, ระดับความมั่นใจของหลักฐานชัดเจน)

## สิ่งที่ควรเปลี่ยน
"เครื่องยนต์ที่ทำให้คนอยากพลิกหน้าต่อ" ไม่ใช่ลายเซ็น ๓ เล่มแรกใช้ลำดับเวลาชีวิตคนคนเดียว ผู้อ่านรู้ตอนจบแล้ว

## ชนิดแกนเรื่อง (เครื่องยนต์) ที่เสนอ — เลือกหนึ่งชนิดใช้ทั้งเล่ม
1. **คำถามเป็นตัวนำ** — ทุกตอนเปิดด้วยคำถามหนึ่งข้อ ไล่หลักฐานหาคำตอบ จบด้วยคำตอบไม่เต็ม + คำถามถัดไป การเทียบหลักฐานเป็นตัวขับเรื่อง
2. **จุดตัดสินใจ** — หยุดที่คืนก่อนการตัดสินใจใหญ่ แสดงตัวเลือกบนแผนที่ เฉลยตอนถัดไปพร้อมหลักฐาน เหมาะงานแม่ทัพ
3. **นาฬิกานับถอยหลัง** — ศึกเดียวมีเส้นตาย (ฤดูน้ำ เสบียง มรสุม) ทุกตอนบอกเวลาที่เหลือ
4. **สลับมุมมองสองฝั่ง** — จบตอนฝั่งหนึ่งกลางเหตุการณ์ ตอนถัดไปเปิดจากอีกฝั่งในนาทีเดียวกัน
- ข้อเสนอเอนไปที่ **ข้อ 1 ผสมข้อ 4**

## รูปแบบเล่ม (โครงที่เปลี่ยนได้)
- ศึกเดียวหรือปีเดียว แทนชีวประวัติ
- สองฝั่ง (ภาคคี่ = สยาม, ภาคคู่ = อีกฝั่ง ใช้แหล่งของฝั่งนั้น)
- เล่มสืบหลักฐาน (ตำนานมาก หลักฐานน้อย ภาคละหนึ่งคำถาม)
- เมืองหรือด่านเป็นตัวเอก (แผนที่ซ้อนยุค)

## ตัวเลือกเรื่อง (ยังไม่ตรวจความพร้อมของแหล่ง)
- สมเด็จพระนารายณ์มหาราช — จดหมายเหตุต่างชาติเยอะ เหมาะแนวสองฝั่ง
- เจ้าพระยาบดินทรเดชา (สิงห์) / ศึกอานามสยามยุทธ รัชกาลที่ ๓ — พงศาวดารไทย + แหล่งเวียดนาม เหมาะศึกเดียว/สองฝั่ง
- พระยาพิชัย (ทองดี ฟันขาว) — ตำนานปนมาก หลักฐานชั้นต้นบาง เสี่ยงกว่า เหมาะเล่มสืบหลักฐาน
- ฝั่งพม่า (บุเรงนอง ฯลฯ) — พลิกมุม แหล่งอังกฤษแปลพงศาวดารพม่า ต้องเตรียมผู้อ่านเรื่องชื่อ/ศัพท์

## โครงตอนที่เสนอ
ฉากเปิด (หลักฐานรองรับ) → แผนที่ → คำถามของตอน → หลักฐานฝั่ง ก. / ฝั่ง ข. → สิ่งที่ยังไม่รู้ → ตะขอไปตอนถัดไป

## กติกาที่ต้องคง (บทเรียนจากเล่ม ๓)
- ฉากเปิดประกอบจากสิ่งที่หลักฐานบอกเท่านั้น (ภูมิประเทศ ฤดู วัสดุ สิ่งของ) ห้ามใส่คำพูด/ความคิดตัวละครที่ไม่มีแหล่ง
- ตอนจบค้างได้ แต่ห้ามค้างด้วยข้อมูลที่ตรวจไม่ได้
- เลือกเรื่องที่ตัวบทชั้นต้นถอดข้อความไว้ออนไลน์แล้ว (Wikisource ฯลฯ) ตรวจความพร้อมของแหล่งก่อนเริ่มเขียน ไม่ให้ซ้ำรอยศึกทวายในเล่ม ๓
- ห้ามอ้างเลขหน้า/ชื่อหนังสือที่ไม่ได้เปิดอ่านจริง

## ค้างอยู่
- ตัวอย่างตอนทดลองหน้าเดียว (เขียนศึกท่าดินแดงใหม่ตามโครงตอนข้างต้น) — เสนอไว้ ยังไม่ได้ทำ
- ตรวจความพร้อมของแหล่ง ๒–๓ ตัวเลือก — ยังไม่ได้ทำ
