# ส่วนหน้า: คำนำและไทม์ไลน์ ๑๕ ปี
**ชื่อหนังสือ:** ๑๕ ปี กระดานศึกพระเจ้าตาก  
**ชื่อรอง:** ๑๕ ปีแห่งไฟสงคราม กลยุทธ์ การสร้างแผ่นดินใหม่ และชะตาแผ่นดินธนบุรี

---

## คำนำ: ห้องยุทธการและพยานในสนามรบ

ประวัติศาสตร์สมัยกรุงธนบุรีมักถูกจดจำผ่านเรื่องเล่าเพียงไม่กี่ฉาก—การตีฝ่าวงล้อมค่ายโพธิ์สามต้น การทุบหม้อข้าวที่เมืองจันทบุรี และการปราบชุมนุมต่างๆ เพื่อรวมแผ่นดิน—ราวกับว่าชัยชนะเหล่านั้นเกิดขึ้นอย่างรวดเร็วและง่ายดาย

แต่หากเรากางแผนที่ภูมิศาสตร์ของแผ่นดินสยามใน พ.ศ. ๒๓๐๙ ออกดูแล้วลองสวมบทบาทเป็นแม่ทัพที่ยืนอยู่กลาง **"ห้องยุทธการ"** คำถามที่แท้จริงจะเปลี่ยนไปโดยสิ้นเชิง:

- เหตุใดกองกำลังเพียง ๕๐๐ นายจึงเลือกตีฝ่าวงล้อมไปทางทิศตะวันออกแทนที่จะหนีขึ้นเหนือหรือลงใต้?
- เหตุใดการตัดสินใจย้ายราชธานีจากอยุธยาลงมาตั้งที่ **"ธนบุรีศรีมหาสมุทร"** จึงเป็นหมากที่เฉียบขาดที่สุดทางเศรษฐกิจและการทหาร?
- และเหตุใดอาณาจักรที่เพิ่งฟื้นจากเถ้าถ่านจึงสามารถรับมือมหาอำนาจอย่างพม่าในศึกบางแก้ว–พิษณุโลก พร้อมกับขยายขอบขัณฑสีมาไปจนถึงล้านนา กัมพูชา และอาณาจักรล้านช้างทั้งสามแห่งได้ภายในเวลาเพียง ๑๕ ปี?

หนังสือ **"๑๕ ปี กระดานศึกพระเจ้าตาก"** เล่มนี้ จึงถูกออกแบบขึ้นด้วยแนวคิด **"การเล่าเรื่องผ่านแผนที่และจุดเปลี่ยนทางอำนาจ" (Map-based Storytelling)** โดยผสานหลักฐานชั้นต้นจากพระราชพงศาวดารกรุงธนบุรี ฉบับพันจันทนุมาศ (เจิม), พระราชพงศาวดาร ฉบับพระราชหัตถเลขา, บันทึกร่วมสมัยของชาวต่างชาติ และงานศึกษาประวัติศาสตร์การเมืองของ **นิธิ เอียวศรีวงศ์** และ **สมเด็จพระเจ้าบรมวงศ์เธอ กรมพระยาดำรงราชานุภาพ** เพื่อพาผู้อ่านมองเห็นทั้ง **"กระดานศึก"** ของผู้บัญชาการรบ และ **"สายตาพยานในสนามจริง"**

ตลอดทั้ง ๔ ภาค ๒๐ ตอน ผู้อ่านจะได้ร่วมเดินทางจากค่ำคืนเดือนมืดที่วัดพิชัย ลัดเลาะชายฝั่งอ่าวไทย ปราบชุมนุมทั้ง ๕ ทั่วราชอาณาจักร เผชิญหน้าจอมทัพเฒ่าอะแซหวุ่นกี้แห่งอังวะ ขุดคลองอ้อมแก่งหลี่ผีพิชิตเวียงจันทน์ จนถึงมรสุมการเมืองลูกสุดท้ายในพระราชวังกรุงธนบุรี—เพื่อเข้าใจอย่างถ่องแท้ว่า แผ่นดินสยามที่ยืนหยัดมาจนถึงทุกวันนี้ ถูกแลกมาด้วยกลยุทธ์ ความกล้าหาญ และการเสียสละมากเพียงใด

---

## เส้นเวลา ๑๕ ปีแห่งกระดานศึก (พ.ศ. ๒๓๐๙ – ๒๓๒๕)

| พ.ศ. | ภาค / ตอน | เหตุการณ์สำคัญบนกระดานศึก |
| :--- | :--- | :--- |
| **๒๓๐๙ – ๒๓๑๐** | ภาค ๑ / ตอนที่ ๑–๓ | พระยาวชิรปราการนำทหาร ๕๐๐ นายตีฝ่าวงล้อมอยุธยา ประกาศตัวเป็น "เจ้าตาก" และทุบหม้อข้าวยึดเมืองจันทบูร |
| **๒๓๑๐** | ภาค ๑ / ตอนที่ ๔–๕ | ต่อเรือรบ ๑๐๐ ลำ ย้อนกลับตีค่ายโพธิ์สามต้นกู้เอกราชภายใน ๗ เดือน และสถาปนากรุงธนบุรีเป็นราชธานีใหม่ |
| **๒๓๑๑** | ภาค ๒ / ตอนที่ ๖–๘ | ศึกบางกุ้งกับการเข้ามาของสองพี่น้อง "บุญมา–ทองด้วง", พ่ายครั้งแรกที่เกยไชย, และปราบชุมนุมพิมายในอีสาน |
| **๒๓๑๒ – ๒๓๑๓** | ภาค ๒ / ตอนที่ ๙–๑๐ | ทัพเรือหลวงปราบชุมนุมเจ้านครศรีธรรมราช และบุกเหนือปราบชุมนุมเจ้าพระฝาง ปิดฉากสงครามรวมแผ่นดิน |
| **๒๓๑๔ – ๒๓๑๗** | ภาค ๓ / ตอนที่ ๑๑–๑๒ | ยุทธการกัมพูชา–ฮาเตียน, วีรกรรมพระยาพิชัยดาบหัก, และจับมือพระยาจ่าบ้าน–เจ้ากาวิละขับพม่าออกจากเชียงใหม่ |
| **๒๓๑๘ – ๒๓๑๙** | ภาค ๓ / ตอนที่ ๑๓–๑๔ | กลศึกล้อม ๓ ชั้นจับทัพพม่าทั้งกองทัพที่บางแก้ว และศึกใหญ่เมืองพิษณุโลกกับจอมทัพพม่า "อะแซหวุ่นกี้" |
| **๒๓๑๙ – ๒๓๒๐** | ภาค ๔ / ตอนที่ ๑๕–๑๖ | ประหารพระยานางรอง, พิชิตจำปาศักดิ์–สี่พันดอน–อัตตะปือ, และสถาปนา "สมเด็จเจ้าพระยามหากษัตริย์ศึก" |
| **๒๓๒๑ – ๒๓๒๒** | ภาค ๔ / ตอนที่ ๑๗ | เหตุสังหารพระวอที่ดอนมดแดง นำสู่ทัพเรือขุดคลองอ้อมแก่งหลี่ผีตีเวียงจันทน์ และอัญเชิญพระแก้วมรกตคืนสู่สยาม |
| **๒๓๒๔ – ๒๓๒๕** | ภาค ๔ / ตอนที่ ๑๘–๒๐ | ศึกกัมพูชาปะทะแนวรบญวน, กบฏพระยาสรรค์ในพระนคร, การเสด็จกลับของทัพใหญ่ และสถาปนากรุงรัตนโกสินทร์ |
