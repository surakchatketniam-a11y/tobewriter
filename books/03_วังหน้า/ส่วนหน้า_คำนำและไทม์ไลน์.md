# ส่วนหน้า: คำนำและไทม์ไลน์ กระดานศึกวังหน้า
**ชื่อหนังสือ:** กระดานศึกวังหน้า  
**ชื่อรอง:** กรมพระราชวังบวรมหาสุรสิงหนาท จากนายสุดจินดาแห่งกรุงเก่า สู่แม่ทัพสงครามเก้าทัพ (พ.ศ. ๒๒๘๖–๒๓๔๖)

---

## คำนำ: แม่ทัพที่อยู่ข้างหลังพระมหากษัตริย์ แต่อยู่หน้าสุดในสนามรบ

ในความทรงจำของคนไทยส่วนใหญ่ เมื่อเอ่ยถึงยุคกอบกู้เอกราชกรุงธนบุรีและต้นกรุงรัตนโกสินทร์ ภาพจำมักจับจ้องอยู่ที่องค์พระมหากษัตริย์สองพระองค์—**สมเด็จพระเจ้าตากสินมหาราช** ผู้ตีฝ่าวงล้อมกอบกู้แผ่นดิน และ **พระบาทสมเด็จพระพุทธยอดฟ้าจุฬาโลกมหาราช** (เจ้าพระยาจักรี ทองด้วง) ปฐมกษัตริย์แห่งราชวงศ์จักรี ทว่าเคียงข้างจอมทัพทั้งสองในแทบทุกสมรภูมิสำคัญ ตั้งแต่ค่ายบางกุ้ง เมืองพิมาย สวางคบุรี พิษณุโลก เชียงใหม่ เวียงจันทน์ ไปจนถึงทุ่งลาดหญ้าในสงครามเก้าทัพ มีขุนพลอีกผู้หนึ่งซึ่งมักยืนอยู่ในแนวหน้าสุดเสมอ

ท่านผู้นั้นคือ **บุญมา**—หรือ **กรมพระราชวังบวรมหาสุรสิงหนาท** พระมหาอุปราช (วังหน้า) พระองค์แรกแห่งกรุงรัตนโกสินทร์

ผู้อ่านหนังสือเล่มที่ ๑ (*กระดานศึกพระเจ้าตาก*) คงคุ้นเคยกับ **เจ้าพระยาสุรสีห์** ในฐานะแม่ทัพคู่กายของเจ้าพระยาจักรีมาแล้ว แต่เรื่องราวเบื้องหลังกลับไม่ค่อยถูกเล่าให้ครบทั้งกระดาน—ตั้งแต่ข้อเท็จจริงที่ว่า ท่านคือน้องชายผู้ก้าวเข้าสู่สนามรบของกรุงธนบุรีก่อน แล้วชักนำพี่ชาย (หลวงยกกระบัตร ทองด้วง) มารับราชการด้วยกัน, ท่านคือแม่ทัพที่รับแรงกระแทกหนักที่สุดของทัพหลวงพม่าที่ทุ่งลาดหญ้าในสงครามเก้าทัพ พ.ศ. ๒๓๒๘, และในยามสงบ ท่านคือผู้สร้าง **พระราชวังบวรสถานมงคล** (ปัจจุบันคือพิพิธภัณฑสถานแห่งชาติ พระนคร) บูรณะ **วัดมหาธาตุยุวราชรังสฤษฎิ์** และอัญเชิญ **พระพุทธสิหิงค์** ลงมาประดิษฐาน ณ พระนคร

หนังสือ **"กระดานศึกวังหน้า"** เล่มนี้จึงชวนผู้อ่านเดินกลับเข้าสู่ห้องยุทธการด้วยสายตาของ **"นักสืบประวัติศาสตร์"** เช่นเดียวกับสองเล่มแรกของชุด เราจะอ่านเหตุการณ์ผ่านภูมิประเทศ เส้นทางเดินทัพ เสบียงอาหาร และฤดูกาล โดยไม่เล่าซ้ำรายละเอียดที่เล่ม ๑ กล่าวไว้แล้ว แต่เจาะลึกจากมุมมองและการตัดสินใจของ **บุญมา–เจ้าพระยาสุรสีห์–กรมพระราชวังบวรมหาสุรสิงหนาท** ควบคู่กับการกางหลักฐานหลายฝ่ายเทียบกัน—ทั้งพระราชพงศาวดารกรุงธนบุรี พระราชพงศาวดารกรุงรัตนโกสินทร์ รัชกาลที่ ๑ พงศาวดารพม่าราชวงศ์คองบอง (*Konbaung Set*) และเอกสารหัวเมืองล้านนา–ปักษ์ใต้

ตลอดเรื่อง เราจะใช้คำเรียกและราชาศัพท์ให้ตรงตามฐานะจริงในแต่ละช่วงเวลา (ใช้ภาษาสามัญเมื่อดำรงฐานะขุนนางตั้งแต่ พ.ศ. ๒๒๘๖–๒๓๒๕ และใช้ราชาศัพท์ระดับพระมหาอุปราชตั้งแต่ พ.ศ. ๒๓๒๕ เป็นต้นไป) พร้อมตรวจสอบข้อขัดแย้งระหว่างหลักฐานอย่างตรงไปตรงมาโดยไม่แต่งเติมเกินจริง—เพื่อทำความเข้าใจบทบาทของแม่ทัพผู้เป็นสะพานเชื่อมระหว่างกรุงศรีอยุธยา กรุงธนบุรี และต้นกรุงรัตนโกสินทร์อย่างรอบด้าน

> *หมายเหตุการใช้ศักราช:* ปี พ.ศ. ในหนังสือเล่มนี้ใช้วิธีนับปีไทยแบบเดิมที่เปลี่ยนขึ้นปีใหม่ในเดือนเมษายน (แปลงจากจุลศักราชโดยบวก ๑๑๘๑) ดังนั้นเหตุการณ์ในช่วงเดือนมกราคม–มีนาคมตามปฏิทินสากลจึงยังคงนับอยู่ในปลายปี พ.ศ. เดิมตามหลักฐานพระราชพงศาวดาร (เช่น เดือนกุมภาพันธ์ ค.ศ. ๑๗๘๗ ตรงกับ จ.ศ. ๑๑๔๘ หรือปลาย พ.ศ. ๒๓๒๙)

---

## เส้นเวลา กระดานศึกวังหน้า (พ.ศ. ๒๒๘๖ – ๒๓๔๖)

| พ.ศ. | ภาค / ตอน | เหตุการณ์สำคัญบนกระดานศึก |
| :--- | :--- | :--- |
| **๒๒๘๖ – ๒๓๑๐** | ภาค ๑ / ตอนที่ ๑ | กำเนิดบุญมาในตระกูลพระอักษรสุนทรศาสตร์ (ทองดี) ที่กรุงศรีอยุธยา รับราชการเป็นนายสุดจินดามหาดเล็ก และหนีออกจากกรุงช่วงเสียกรุง พ.ศ. ๒๓๑๐ |
| **๒๓๑๐ – ๒๓๑๑** | ภาค ๑ / ตอนที่ ๒ | เข้าร่วมทัพพระยาตาก ได้เป็นพระมหามนตรีนำทัพหน้าตีค่ายพม่าที่บางกุ้ง และชักนำหลวงยกกระบัตร (ทองด้วง) เข้ารับราชการเป็นพระราชวรินทร์ |
| **๒๓๑๑ – ๒๓๑๓** | ภาค ๑ / ตอนที่ ๓ | เลื่อนเป็นพระยาอนุชิตราชาหลังศึกพิมาย ร่วมตีเสียมราฐ เลื่อนเป็นพระยายมราชคุมทัพบกปราบชุมนุมพระฝาง และเป็นเจ้าพระยาสุรสีห์ครองเมืองพิษณุโลก |
| **๒๓๑๕ – ๒๓๑๘** | ภาค ๑ / ตอนที่ ๔ | ช่วยพระยาพิชัยตีทัพโปสุพลาแตกสองครั้ง และร่วมกับเจ้าพระยาจักรี พระยาจ่าบ้าน (บุญมา) และเจ้ากาวิละตีเมืองเชียงใหม่สำเร็จ |
| **๒๓๑๘ – ๒๓๑๙** | ภาค ๒ / ตอนที่ ๕ | รักษาเมืองพิษณุโลกรับศึกอะแซหวุ่นกี้กว่าสี่เดือนก่อนตีฝ่าวงล้อมออกไปทางเพชรบูรณ์ |
| **๒๓๑๙ – ๒๓๒๐** | ภาค ๒ / ตอนที่ ๖ | ร่วมทัพเจ้าพระยาจักรีผ่านลุ่มน้ำมูลไปตีเมืองจำปาศักดิ์ |
| **๒๓๒๑ – ๒๓๒๒** | ภาค ๒ / ตอนที่ ๗ | คุมทัพเรือขุดคลองอ้อมแก่งหลี่ผีขึ้นไปสมทบทัพบกล้อมเวียงจันทน์ และอัญเชิญพระแก้วมรกตกลับกรุงธนบุรี |
| **๒๓๒๔ – ๒๓๒๕** | ภาค ๒ / ตอนที่ ๘ | ศึกกัมพูชา วิกฤตกรุงธนบุรี และการสถาปนาขึ้นเป็นกรมพระราชวังบวรมหาสุรสิงหนาท (วังหน้า) |
| **๒๓๒๗ – ๒๓๒๘** | ภาค ๓ / ตอนที่ ๙–๑๐ | สงครามเก้าทัพของพระเจ้าปดุง วังหน้านำทัพรับศึกหลักที่ทุ่งลาดหญ้า กาญจนบุรี ตัดเสบียงจนทัพพม่าแตก |
| **๒๓๒๘ – ๒๓๓๐** | ภาค ๓ / ตอนที่ ๑๑–๑๒ | ยกทัพลงใต้ขับไล่พม่าจนถึงปัตตานี และร่วมศึกท่าดินแดงปิดฉากการรุกใหญ่ของราชวงศ์คองบอง |
| **๒๓๒๕ – ๒๓๓๘** | ภาค ๔ / ตอนที่ ๑๓ | สร้างพระราชวังบวรสถานมงคล บูรณะวัดสลัก (วัดมหาธาตุ) และอัญเชิญพระพุทธสิหิงค์จากเชียงใหม่ |
| **๒๓๓๐ – ๒๓๔๐** | ภาค ๔ / ตอนที่ ๑๔–๑๕ | แนวรบตะวันตกที่ทวาย–ตะนาวศรี และการป้องกันล้านนาในศึกเชียงใหม่ พ.ศ. ๒๓๔๐ |
| **๒๓๔๕ – ๒๓๔๖** | ภาค ๔ / ตอนที่ ๑๖ | เสด็จกรีฑาทัพขึ้นช่วยเชียงใหม่ครั้งสุดท้ายแม้ประชวร และเสด็จสวรรคตใน พ.ศ. ๒๓๔๖ |
